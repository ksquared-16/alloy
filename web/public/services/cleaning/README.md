# Cleaning service photos

Add these image files here for the `/services/cleaning` page:

| Filename          | Used for              |
|-------------------|------------------------|
| `standard.jpeg`   | Standard cleaning      |
| `deep-cleaning.jpeg` | Deep cleaning       |
| `moveout.jpeg`    | Move-out cleaning      |

Supported formats: `.jpeg`, `.jpg`, or `.webp`. Use the same base name if you use a different extension (e.g. `standard.jpg`).
