Locations / Rooms

Rooms = Location-owned units (parent_location_id). Not org-defined, not reusable templates, not inherited.

  • Schedules · capacity metadata/rules · tours → Location-scoped
  • Placement → Business Process–owned ranking, surfaced on Location
  • Access tab → site-scope assignment (not inheritance)
