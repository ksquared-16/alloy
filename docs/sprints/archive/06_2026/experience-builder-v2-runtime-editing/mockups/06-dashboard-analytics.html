The dashboard is just a Design Surface. Same Edit Bar, same Structure/Content modes, same +-between-cards. A Metric card's data source is a metric ref (math owned by Operational Intelligence ↗); here you choose only its visualization.
Analytics is identical
There is no separate analytics builder. Editing a dashboard feels exactly like editing a Focus Panel or Queue Row.
Only two things change: Card Type = Metric and the Renderers are analytics renderers (KPI, Trend, Sparkline, Chart, Gauge, Table).
Metric math stays in Operational Intelligence. This surface owns placement + visualization only.
