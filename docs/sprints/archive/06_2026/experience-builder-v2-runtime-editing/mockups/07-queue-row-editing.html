You edit the row inside the real queue, beside its neighbors — not in a separate row configurator. Selecting a row zone (header.primary) reveals its slots; the inline editor is the same one used on Focus Panel cards.
One model, every surface
A Queue Row is edited with the same Edit Bar, the same Structure/Content modes, and the same inline editors as a Focus Panel.
Only the zone topology (header.primary / secondary / context / body / actions) and the 52px height constraint differ.
Rows remain previews — authoritative detail still comes from entity GET.
