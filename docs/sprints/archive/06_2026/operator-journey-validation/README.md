# Operator Journey Validation Sprint (June 2026)

Validates that the **complete operator experience** feels natural before the
remaining archetype cards are implemented. No new architecture, no new primitives.

The operator never experiences cards individually — they experience one Focus
Panel whose Operational Context recomposes cards as the subject changes,
perspective changes, and work completes. This sprint pressure-tests that
choreography.

## Deliverable

- [`alloy-interaction-story-001-enrollment.md`](./alloy-interaction-story-001-enrollment.md)
  — 10-scene enrollment storyboard with per-frame annotations (Perspective /
  Subject / Context / network / recomposition / animation), a whole-story
  choreography ledger, pressure-test answers, and one final recommendation.

## Outcome

**The interaction model is approved.** Architecture and interaction model freeze;
remaining archetype cards proceed to implementation; Experience Builder
integration begins.
