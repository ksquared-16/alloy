# Deferred builder / presentation (E2.6 notes)

Not implemented in V1.6.1 — captured for future cards (E3+):

- Logo / branding blocks on public forms
- Section headers beyond a single primary section title
- Static text / rich text paragraphs between fields
- AI-generated field help or labels
- AI-suggested form templates or packet composition
- Rich layout blocks (multi-column grids, cards, tabs)
- Drag-and-drop field ordering (current flow uses explicit ordering controls)

Operational forms continue to use **FormSchemaV1** only; any future block types must extend that contract deliberately.
