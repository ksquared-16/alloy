GHL Custom Field ID Fetch (LeadConnector / GHL)

1) List ALL contact custom fields for a location:
curl -s "https://services.leadconnectorhq.com/locations/<LOCATION_ID>/customFields" \
  -H "Authorization: Bearer <PIT_TOKEN>" \
  -H "Version: 2021-07-28" | python -m json.tool

2) Find ONE field by fieldKey:
curl -s "https://services.leadconnectorhq.com/locations/<LOCATION_ID>/customFields" \
  -H "Authorization: Bearer <PIT_TOKEN>" \
  -H "Version: 2021-07-28" \
| jq -r '.customFields[] | select(.fieldKey=="contact.estimated_price_contact")'

3) Output a clean mapping: "FIELDKEY = ID"
curl -s "https://services.leadconnectorhq.com/locations/<LOCATION_ID>/customFields" \
  -H "Authorization: Bearer <PIT_TOKEN>" \
  -H "Version: 2021-07-28" \
| jq -r '.customFields[] | "\(.fieldKey) = \(.id)"'

4) Quick search by name contains "Estimated Price"
curl -s "https://services.leadconnectorhq.com/locations/<LOCATION_ID>/customFields" \
  -H "Authorization: Bearer <PIT_TOKEN>" \
  -H "Version: 2021-07-28" \
| jq -r '.customFields[] | select(.name|test("Estimated Price";"i")) | "\(.name) | \(.fieldKey) | \(.id)"'
